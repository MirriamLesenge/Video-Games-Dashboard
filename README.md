# 🎮 Video Game Sales & Marketing Performance Dashboard
📊 Project Overview

This project is an interactive Power BI dashboard developed to analyze the sales and marketing performance of a video game business.

As a Data Analyst, I used the dataset to investigate revenue, units sold, marketing spend, return on investment, game performance, developer performance, genre performance, and regional trends.

The objective was to transform raw sales data into a dashboard that provides both a high-level business overview and detailed insights into the games and developers driving performance.

🎯 Business Questions

The dashboard was designed to answer key business questions such as:

How many games are in the portfolio?
What is the total revenue generated?
How many units have been sold?
How much has been spent on marketing?
Which genres generate the most revenue?
Which genres have the highest number of units sold?
Which regions generate the most revenue?
How has revenue changed over time?
Which games generate the most revenue?
Which games sell the most units?
Which developers generate the most revenue?
Which games have the highest marketing ROI?
How efficiently is marketing spend generating revenue?
🗂️ Data Modelling

The project initially started with a wide table containing the different game, sales, marketing, and date-related fields.

As part of the data modelling process, I transformed the wide-table structure into a more organized dimensional model consisting of:

📌 Fact Table

Video Games Fact Table

The fact table contains the measurable sales and marketing information, including:

Game_ID
Sale_ID
Sale_Date
Release_Date
Units_Sold
Unit_Price
Discount_Pct
Revenue
Marketing_Spend
Critic_Score
📌 Dimension Tables
Dim Video Games

This dimension contains descriptive information about the games, including:

Game_ID
Title
Genre
Developer
Publisher
Platform
Region
Dim Date

A dedicated date dimension was created to support accurate time-based analysis.

The date table contains fields such as:

Date
Date_ID
Month Name
Month Number
Quarter
Year
Year-Month

Using a dedicated Dim Date allowed the dashboard's time-based visuals and line graphs to use a consistent date structure and avoid gaps in the time analysis.

🏆 Top 10 Games by Revenue

This visual identifies the 10 games generating the highest revenue.

It helps highlight the products that are contributing the most to overall business revenue.

📦 Top 10 Games by Units Sold

A separate visual ranks the 10 games with the highest number of units sold.

This provides a different perspective from revenue because a game can have high sales volume without necessarily generating the highest revenue.

👨‍💻 Top 5 Developers by Revenue

This visual identifies the top five developers based on revenue generated by their games.

This allows the business to understand which developers are contributing most significantly to financial performance.

💰 Top 5 Games by Marketing ROI

This visual identifies the five games with the highest marketing ROI.

Marketing ROI was used to evaluate how efficiently marketing investment translated into revenue.

The dashboard recorded an overall Marketing ROI of approximately:

10.45x

This means that, based on the dataset, approximately R10.45 in revenue was generated for every R1 spent on marketing.

💡 Key Business Insights

The dashboard allows the business to identify several important performance patterns.

Genre Performance

Shooter games are among the strongest-performing genres for both revenue and units sold in the dataset.

Regional Performance

North America generates the highest revenue among the regions analyzed, followed by Europe.

Revenue Trend

Revenue changes across the years, with a decline between 2021 and 2022 followed by continued growth through 2025.

Game Performance

The Top 10 analysis makes it possible to identify the individual games that contribute the most revenue and sales volume.

Developer Performance

The Top 5 developer analysis highlights which developers contribute significantly to overall revenue.

Marketing Efficiency

Marketing ROI provides another perspective on performance by showing that high revenue alone does not necessarily mean marketing was efficient.

A game with lower revenue can potentially have stronger ROI if it generated that revenue using significantly less marketing spend.
